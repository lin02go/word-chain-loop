# 双语改版方向稿 · 共同设计说明

这次不是把英文按钮机械替换成中文，而是要让第一次打开页面的中文玩家在十秒内明白三件事：这是什么游戏、下一步要做什么、怎样才算赢。同时保留英文界面，让游戏既适合国内玩家，也能继续服务英语学习者和海外用户。现有项目已经形成鲜明的纸张、词典与报刊编辑部气质，因此三个方向都从这个基础上生长，不引入无关插画，也不把页面改成常见的霓虹渐变游戏模板。游戏内容仍然是英文单词；“汉化”针对界面、提示、规则、错误信息和结果页，不翻译玩家实际输入的英文词。

目标受众包括喜欢文字游戏的普通玩家、正在积累英语词汇的学习者，以及希望快速开始、不愿先读长说明的移动端用户。核心信息顺序固定为：短名称与一句话玩法、当前首尾目标、当前词链、输入动作、必要提示、简短规则。中文默认使用清楚自然的口语，不使用“节点”“图搜索”“词项”等实现术语；规则用五步以内的短句表达，并在关键位置重复“接最后两个字母”这条唯一核心机制。语言切换必须始终可见，按钮本身同时出现“中文 / English”或“中 / EN”，避免用户进入看不懂的语言后找不到切换入口。切换后同步更新页面标题、按钮、辅助说明、ARIA 标签与胜利弹窗；玩家输入、当前词链、难度和本局进度不应重置。语言选择建议保存到本地，下次打开沿用。

三个方向统一以桌面端 1440×900 为比较尺寸，并兼顾 680px 以下移动端。所有正文不低于 14px，中文正文建议 16–17px、1.7 左右行高；英文数字优先由西文字体承接，中文由思源/苹方/微软雅黑兜底，禁用合成斜体。页面色彩继续使用暖纸色、墨黑和少量蓝/红/绿作为首字母、尾字母与重叠状态的功能色。三版使用相同的真实游戏内容：起始词 `algebra`，目标从 `al` 回到 `al`，示例链为 `algebra → rabbit → italic`，方便只比较设计差异。

视觉母题来自游戏规则本身：每个单词把末尾两个字母“交给”下一个单词，最后首尾合拢。方向一把它解释成词典编辑部的校样与批注；方向二把它解释成互相扣合的活字块；方向三把它解释成沿着字母轨道回到起点的一段短旅程。图片不是信息必需品，因此三版均不用装饰图片，以排印、连线、颜色和留白完成表达。

三个名称候选分别是：“词环 / Word Loop”（最清楚、最适合长期品牌化）、“词扣 / WordLink”（更有动作感，突出两字母咬合）、“回环词 / Loopword”（更有文字游戏气质，但第一眼理解成本略高）。建议最终优先选“词环”，它只有两个字，读写和记忆成本最低，也准确表达游戏目标。
